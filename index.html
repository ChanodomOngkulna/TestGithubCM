Git Command Cheatsheet

คู่มือรวมคำสั่ง Git สำหรับการทำงานร่วมกัน การแก้ Conflict และย้อนเวอร์ชัน

Workflow การทำงานร่วมกันหลายคนใน 1 Repo (แนะนำ)

Step 1

ดึงโค้ดล่าสุดจาก main

ก่อนเริ่มงานใหม่ทุกครั้งเพื่อป้องกันโค้ดล้าสมัย

git pull origin main
Step 2

สร้าง Branch ใหม่

แยกทำเฉพาะฟีเจอร์ของตนเอง ไม่แก้บน main ตรงๆ

git checkout -b my-feature
Step 3

Commit & Push งาน

บันทึกและส่ง Branch ขึ้น GitHub เพื่อขอรวมโค้ด

git push -u origin my-feature
Step 4

ทำ Pull Request (PR)

ส่งคำขอ Merge ให้เพื่อนช่วยตรวจโค้ดก่อนรวมเข้า main

ทำผ่านหน้าเว็บ GitHub

ไม่พบคำสั่งที่ค้นหา

ลองค้นหาด้วยคำอื่นๆ เช่น branch, log, reset

คัดลอกคำสั่งแล้ว!
